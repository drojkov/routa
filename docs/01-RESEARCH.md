## 2. Бизнес-модель

Схема у всех одна:

1. **Закупка.** Сервис платит вендорам (OpenAI, Anthropic, Google и др.) в долларах со своих аккаунтов. ProxyAPI прямо пишет, что запросы уходят через цепочку прокси в Европе, а нагрузка распределяется по «пулам аккаунтов высокого тира».
2. **Продажа.** Клиент пополняет рублёвый баланс, и каждый запрос списывается по фиксированной рублёвой цене за 1M токенов (изображение, секунду видео).
3. **Маржа** складывается из трёх частей:
   - наценка на цену вендора. Цифры в явном виде никто не публикует, а сравнить с прайсом вендоров я не могу: точных актуальных цен вендоров у меня нет;
   - курсовой запас: рублёвая цена фиксирована, поэтому курс в неё заложен с запасом;
   - неизрасходованный остаток на балансах. Возврат возможен, но только по заявке (у RouterAI: 3 рабочих дня на рассмотрение, 10 на выплату).
4. **B2B** — отдельный канал выручки: договор, счёт, закрывающие документы, ЭДО. Компании не могут платить иностранным вендорам, поэтому для них это главный аргумент.
5. **Поставка (только у RouterAI).** Маркетплейс: владельцы GPU разворачивают open-source модели и продают инференс через платформу. Трафик распределяется по цене и аптайму, выплаты раз в месяц. Такой сервис уже работает как биржа, а не как простой реселлер.

Точки роста, которые они используют в маркетинге:
- уход OpenRouter из РФ (приём платежей прекращён 12.05.2026, полная блокировка 27.06.2026). У обоих российских сервисов есть лендинг «Замена OpenRouter»;
- вайб-кодинг и coding-агенты (Claude Code, Cursor, Cline): гайды «как подключить»;
- 152-ФЗ и серверы в РФ для корпоративных клиентов.

## 3. Архитектура (по публичным признакам)

```
Клиент (SDK OpenAI/Anthropic, curl, Cursor…)
   │  Authorization: Bearer <ключ сервиса>
   ▼
API-шлюз сервиса (РФ)
   ├─ аутентификация ключа, проверка лимитов ключа (бюджет, модели, IP)
   ├─ предварительная проверка баланса: вход + max_tokens × цена → 402, если не хватает
   ├─ маскирование ПДн (опционально)
   ├─ маршрутизация: модель → провайдер → конкретный аккаунт/ключ из пула
   │     (fallback при ошибке, cooldown ключа после 429)
   ▼
Прокси-цепочка за рубежом ──► OpenAI / Anthropic / Google / …
   ▲
   └─ ответ (в том числе стрим SSE) идёт обратно; по полю usage считается
      фактическая стоимость → списание с баланса → запись в лог
```

Что видно из документации ProxyAPI:
- **Биллинг:** `стоимость = (вход × цена_входа + выход × цена_выхода) / 1 000 000`. Отдельно учитываются reasoning-токены, кэш и веб-поиск. Перед запросом проверяется «вход + максимально возможный выход», но деньги не резервируются.
- **Rate limits:** 429 на всё. После 20 ошибок 4xx за минуту ключ ставится на паузу с растущим сроком: 1 мин → 10 мин → 1 ч → 12 ч. Так сервис защищает свои вендорские аккаунты от бана за мусорный трафик.
- **Ключи:** у каждого ключа свой бюджет, белый список моделей, белый список IP и право на `GET /balance`.
- **Контроль расходов:** письмо при низком балансе, месячный бюджет аккаунта.

## 4. Структура сайта (общий знаменатель)

- **Лендинг:** оффер («без VPN, оплата в рублях»), «как это работает» в 3 шага, преимущества, цифры (клиенты, токены в день), блок «для бизнеса», CTA «создать ключ».
- **Каталог моделей:** поиск, фильтры (модальность, вендор, цена, контекст, возможности), сортировка, цены за 1M вход/выход. ProxyAPI дополнительно делит модели по тиру: флагманская, универсальная, быстрая, экономичная.
- **Карточка модели:** ID, описание, контекст, max output, дата релиза, возможности (vision, tools, reasoning, кэш, PDF), цены (вход, выход, чтение и запись кэша, веб-поиск), примеры кода (Python, Node, cURL), playground, похожие модели, FAQ.
- **Документация:** быстрый старт, ключи, модели, API по протоколам, модальности, ошибки, лимиты, баланс, стоимость, гайды по интеграциям.
- **Личный кабинет:** баланс и пополнение, API-ключи, статистика и логи, лимиты, команда, документы для юрлиц.
- **Чат:** веб-интерфейс для людей без кода. Это отдельная аудитория.
- **SEO-лендинги:** «Замена OpenRouter», «Вайб-кодинг», «Enterprise», «Команды», «Генерация видео», глоссарий, блог.
- **Юридическое:** оферта, политика конфиденциальности, возвраты.
